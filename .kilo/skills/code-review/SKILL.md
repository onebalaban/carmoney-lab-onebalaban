# Ревью перед мержем
Стандарт ревью перед мержем.
1. Прочитай AGENTS.md и указанный файл/дифф; найди вызывающий код.
2. Проверь SQL-инъекции, транзакции записи, обработку ошибок, контракты и границы.
3. Сообщай только подтверждённые проблемы с реальным сценарием.
4. Для каждой: P1/P2/P3, файл:строка, сценарий, последствие, минимальное исправление, проверка.
5. Заверши вердиктом и перечисли непроверенное. Если проблем нет — так и скажи.
6. Результат по шаблону template.md — в чат; файл только по явному запросу, в docs/plan/.
7. Не исправляй код во время ревью; не меняй пороги и тесты ради результата ревью.
Это проверка кода, а не intent, spec или план реализации.
