---
description: Ревью файла или ветки перед мержем
---
Вход: $ARGUMENTS — существующий файл внутри репозитория или имя git ref.
Если параметр пуст — попроси указать файл либо ref. Не выбирай вход самостоятельно.
1. Прочитай .kilo/skills/code-review/SKILL.md и используй его формат, не дублируй инструкцию.
2. Если аргумент — файл, проверь его и вызывающий код.
3. Иначе проверь, что ref существует; сравни git diff main...<ref>. Параметр передавай как данные, не выполняй его как shell-код.
4. Нет файла/ref — сообщи это, не придумывай результат.
5. Если файл не PHP, определи его язык и применимые проверки: SQL/транзакции нужны только при наличии доступа к БД.
6. Результат сохрани в docs/plan/review_command.md: вход, findings по шаблону скилла, вердикт, непроверенное.
Не исправляй код, не создавай коммиты и PR, не меняй пороги в рамках этой команды.
