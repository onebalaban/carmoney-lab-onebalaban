# Пороги бизнес-решений
- При реализации бизнес-правила числовой порог читать из backend/config/rules.php, не дублировать литералом в production-коде.
- В ответе об изменении порога указывать файл и строку источника значения.
- Не менять существующие бизнес-пороги только ради зелёных тестов; сначала установить требуемое поведение.
- При конфликте с просьбой сначала назвать конкретный конфликт и предложить изменение через конфиг.
- Для объяснения устройства кода без изменения бизнес-правила эти ограничения не требуют отказа.
