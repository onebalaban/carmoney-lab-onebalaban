# Замысел
При пробеге больше 400000 км направлять допустимую заявку на review вместо approve.
Источник: формулировка задания 1.5.1; учебное решение 3 в grill_MILEAGE.md.

# Зачем
Не одобрять автоматически автомобили с большим пробегом.

# Constraints
- 400000 км включительно не меняет решение; больше — review, если нет reject. Источник: задание; учебные решения 1, 3, 4.
- Reject по LTV сохраняется. Источник: учебное решение 4; код: backend/src/Domain/DecisionEngine.php.
- Отсутствующий, пустой, null и неизвестный пробег — ошибка, не ноль. Источник: учебное решение 2 (уточняет обработку пустой строки).
- Свыше 500000 км — ошибка. Источник: код: backend/config/rules.php; учебное решение 5.
- Для review одобренный лимит равен 0. Источник: код: backend/src/Domain/AssessmentService.php.
