# Замысел
При пробеге больше 400000 км направлять допустимую заявку на review вместо approve.
Источник: формулировка задания 1.5.1; решение протокола 3 в grill_MILEAGE.md.

# Зачем
Не одобрять автоматически автомобили с большим пробегом.

# Constraints
- 400000 км включительно не меняет решение; больше — review, если нет reject. Источник: задание; решения протокола 1, 3, 4.
- Reject по LTV сохраняется. Источник: решение протокола 4; код: backend/src/Domain/DecisionEngine.php.
- Отсутствующий, пустой, null и неизвестный пробег — ошибка, не ноль. Источник: решение протокола 2 (уточняет обработку пустой строки).
- Свыше 500000 км — ошибка. Источник: код: backend/config/rules.php; решение протокола 5.
- Для review одобренный лимит равен 0. Источник: код: backend/src/Domain/AssessmentService.php.

# Open questions
- Открыт: нужен ли отдельный reason code? Адресат — владелец продукта, пока не реализуем.
- Закрыты в протоколе: включительность границы, пустой пробег, приоритет reject (протокол выше).

# Не входит
Изменение LTV, базы и формы; внешняя проверка VIN; reason codes. Источник: решение протокола 6.
