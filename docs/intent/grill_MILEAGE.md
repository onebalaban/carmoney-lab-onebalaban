# 1.5.1: учебный протокол Grill Me
Работу выполняет Codex. Это не запись ответов пользователя и не сессия Kilo.
Пользователь разрешил выбрать любое решение; ниже решения агента для учебной реализации.

1. 400000 входит в допустимую границу? Да: по формулировке задания «не больше».
2. Что делать без пробега? Сохранить ошибку валидации; неизвестный пробег не считать нулём.
3. Превышение перекрывает approve? Да, понижает approve до review.
4. Может ли review отменить reject по LTV? Нет: сохраняем более строгое решение reject.
5. Что с пробегом выше 500000? Сохранить действующую ошибку валидации.
6. Что вне задачи? Изменение LTV, базы, формы, внешние проверки автомобиля.

Открытый вопрос владельцу продукта: нужен ли отдельный reason code для большого пробега? Не блокирует базовую фичу.
