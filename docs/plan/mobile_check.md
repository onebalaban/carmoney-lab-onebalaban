# ДЗ 2.6: проверка на мобильном эмуляторе

## Сценарий
1. Подключить мобильный MCP к Kilo и выбрать запущенный Android/iOS эмулятор.
2. Открыть форму: Android — http://10.0.2.2:8080, iOS — http://localhost:8080.
3. Оставить синтетические VIN XTA21099998765432, год 2019, стоимость 900000, сумму 450000, срок 24; пробег заменить на 400001.
4. Нажать «Отправить заявку».
5. Проверить review, LTV 50 %, одобренный лимит 0; снять скриншот полного результата.
6. Проверить доступность кнопки на узком экране и отсутствие перекрытия клавиатурой.

## Результат
Прогон не выполнялся: по просьбе владельца приложение больше не поднимаем. Скриншот эмулятора не получен.
Ожидаемый результат указан по правилу из ДЗ.1, это не наблюдение мобильного клиента.
Существующий браузерный результат приложен к PR #8; его нельзя считать эмулятором.

## Отличие от desktop
Нужны маршрутизация до хоста, работа с экранной клавиатурой и прокруткой, выбор эмулятора. Viewport мобильного размера в Chromium не заменяет Android/iOS.

Зависимость: PR #7 с правилом пробега. Повторять только когда будет разрешён запуск сервиса и доступен эмулятор.
